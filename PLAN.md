# CS509 — Mini Project II — PLAN

**Semester:** 5 · **Credits:** 2 · **Level:** Advanced
**Theory:** 0 hrs · **Lab:** 30 hrs · **Tools:** Your stack of choice; Git + GitHub for everything

## Project Format
Individual or paired project. Builds on one of the Semester 5 theory subjects (AI, ML, Security, Compilers, Data Science, NLP) and produces a working prototype with a short written report.

## Topic Areas (choose one)

### Track A — AI / Machine Learning Application
1. An NLP-based sentiment analyser for product reviews
2. A recommender system for movies or books
3. An image classifier for a specific domain (plant diseases, waste categories)
4. A chatbot grounded in a small document corpus (RAG)
5. A time-series forecasting tool for a public dataset

### Track B — Security Tool
6. A port scanner with a clean UI and report output
7. A password strength analyser with breach-database lookup
8. A static analyser for a small language (detect common bugs)
9. A log analyser for detecting suspicious patterns
10. A simple vulnerability scanner for web apps (educational)

### Track C — Compiler / Language Tool
11. A mini compiler for a toy language (arithmetic + variables)
12. A linter for Python or JavaScript with configurable rules
13. A pretty-printer for an existing language
14. An interpreter for a small DSL
15. A transpiler from a simple language to Python

### Track D — Data Science Product
16. An interactive dashboard for a public dataset
17. A/B test analysis toolkit
18. A data cleaning automation tool
19. A reporting pipeline that turns CSVs into PDFs
20. An ETL pipeline with scheduling

## Milestones

### Milestone 1 — Proposal (Week 2)
- One-page proposal: problem, users, approach, milestones
- Track and topic chosen
- GitHub repo created

### Milestone 2 — Design (Week 4)
- Architecture diagram
- Data model (if any)
- Key algorithms / techniques identified
- Tech stack justified

### Milestone 3 — Prototype (Week 8)
- Minimum viable version working
- Tests for the core
- First demo (self-recorded)

### Milestone 4 — Full Build (Week 12)
- All planned features complete
- Tests passing
- Documentation written

### Milestone 5 — Final (Week 15)
- Live demo
- Report submitted
- Reflection on what you would do differently

## Deliverables

- GitHub repo with clear `README.md` and setup instructions
- `DESIGN.md` — architecture and decisions
- `REPORT.md` — 2000-word written report on the problem, approach, results, and limitations
- Working demo (video or deployed)
- Tests — at least 10 test cases passing

## Assessment

| Component | Weight |
| :--- | :---: |
| Proposal + design | 15% |
| Weekly commits and progress | 15% |
| Working prototype quality | 30% |
| Report (clarity, rigour, honesty) | 20% |
| Final demo and reflection | 20% |

## Anti-patterns to Avoid

- Building a CRUD app with no technical depth
- Copying a tutorial end to end
- No tests
- A report that claims more than the demo shows
- A demo that only works on the author's laptop
